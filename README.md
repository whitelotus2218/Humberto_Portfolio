# Project 1: Customer Churn Analytics, behavioral profiling & predictive modeling
•	Tech Stack & Pipeline:
  o	SQL Server ──> Excel (.xlsx) ──> Python (Scikit-Learn) ──> Power BI <br/>
     (Cleaning)      (Storage)        (Lasso, RF & LogReg)      (Dashboards)<br/>
•	Data Cleaning & EDA (SQL Server):<br/>
  o	Handled missing values, data types, and initial exploration using SQL Server Management Studio.<br/>
•	Preprocessing (Python):<br/>
  o	Applied Label Encoding, feature scaling, and feature selection via Lasso Regularization to isolate key drivers of churn.<br/>
•	Machine Learning:<br/>
  o	Trained a baseline Logistic Regression model.<br/>
  o	Optimized Random Forest using RandomizedSearchCV.<br/>
  o	Evaluated models using ROC-AUC and classification reports.<br/>
•	Business Intelligence (Power BI):<br/>
  o	Customer Profile Report:<br/>
   	Behavioral segmentation and demographic overview.<br/>
  o	Churn Executive Dashboard:<br/>
   	Churn rates and risk factor analysis.<br/>
